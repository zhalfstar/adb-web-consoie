网络抓包

需要盒子里有 tcpdump 且 adb shell 具备 root。抓取结果保存为 /sdcard/adbweb_capture.pcap，停止后自动 pull 到电脑，可用 Wireshark 打开。

如果没有 tcpdump，请改用「日志」页抓 logcat，或用 Shell 执行 netstat / dumpsys connectivity 查看网络状态。
